# Project Instructions

This project uses the local SDD method stored in `sdd/`.

Before making product or code changes:

1. Read `sdd/README.md`.
2. Read `sdd/method.md`.
3. Check `sdd/project-context.md`.
4. For a concrete task, create or update a spec in `sdd/specs/` unless the task is trivial.
5. If the change creates a non-obvious technical or product decision, record it in `sdd/decisions/`.
6. If the change needs audit, handoff, or later analysis, create a review note in `sdd/reviews/`.

Keep SDD documents concise and useful. The method should help move the project forward, not become paperwork.
