# Decisions

Здесь фиксируются решения, которые неочевидны из кода или важны для будущих изменений.

## Шаблон

```markdown
# Decision 000: Название

## Дата

YYYY-MM-DD

## Статус

Accepted | Replaced | Rejected

## Контекст

Почему понадобилось решение.

## Решение

Что выбираем.

## Альтернативы

Что рассматривали.

## Последствия

Что это упрощает, усложняет или ограничивает.
```
