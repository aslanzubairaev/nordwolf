# Specs

Каждый spec описывает одну законченную задачу или продуктовый сценарий.

## Шаблон

```markdown
# Spec 000: Название

## Статус

Draft | In progress | Done | Paused

## Контекст

Что уже есть и где это находится.

## Проблема

Что нужно изменить и почему.

## Цель

Как выглядит готовое состояние.

## Сценарии

- Пользователь ...
- Система ...

## Границы

Что не входит в задачу.

## Данные и код

- Модели:
- Сервисы:
- Команды:
- UI:

## Проверка

- Автотесты:
- Ручная проверка:
- Сборка:

## Итог

Что реализовано и какие выводы появились.
```
