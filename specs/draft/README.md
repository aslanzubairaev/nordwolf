# Draft Specifications

Draft ordinary specs are working documents.

They may be incomplete, contain unresolved isolated-agent review notes and reference future specs for authoring context.

Draft ordinary specs are not declared in `specs/accepted/manifest.json`.

Strict manifest and relationship validation applies only after a spec is accepted and moved to `specs/accepted/`.

Draft and Review Change Requests live in `specs/change-requests/`, not in this folder.
